# Social Campaign Manager: Prompt-Driven Poster Agent

Create posters for events, education, awareness, research, safety, promotion, and other purposes from a natural-language brief. The agent generates structured copy and a visual theme, renders a self-contained HTML design, and offers browser preview, HTML download, and A3 print/PDF.

## Run locally

From this directory's parent (`Biomarker/`):

```sh
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r poster_agent/requirements.txt
```

Set `OPENAI_API_KEY` in `Biomarker/.env`, or export it in the shell. Optionally set `OPENAI_MODEL` and `OPENAI_API_URL` for an OpenAI-compatible provider. Never commit `.env`.

Start the standalone poster app:

```sh
python3 -m poster_agent.server
```

Open <http://127.0.0.1:8766/>. Describe purpose, audience, tone, and exact content. Download the generated HTML to keep an editable poster, or use **Print / save PDF** to make an A3 PDF.

The server binds only to localhost and exposes only the poster interface and generation API. Poster copy is generated by the configured language-model agent, not handwritten. Review names, dates, addresses, statistics, and citations before publishing; the model does not independently fact-check the result.

## Functional modules

- `prompt/`: system instructions and user brief packaging.
- `content/`: model request and structured-response validation.
- `design/`: approved design themes.
- `rendering/`: escaped, self-contained printable HTML output.
- `ui/`: prompt form, preview, download, and print controls.
- `tests/`: offline unit tests; run them from `Biomarker/` with `python3 -m unittest poster_agent.tests.test_poster_agent -v`.
